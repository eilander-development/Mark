# IronForge

Periodized workout tracker (thuisgym). Ombouw van de AI Studio-export naar een echte installeerbare PWA.

**Stack:** Vue 3, TypeScript, Vite, Tailwind, IndexedDB, `vite-plugin-pwa`. Later PHP + MariaDB op Plesk. Geen React, geen Nuxt.

Zie [PLAN.md](./PLAN.md) voor de stappen: lokale app, PWA zonder browserbalk, datamodel, Val Town-import, daarna finetunen.
